# 教学 PPT 与读写材料改造 V2.0

将用户材料做成内容准确、构图完整、可实际使用的成品。融合原高审美工作流与《梳理与探究读写进阶》两轮改版的经验。保留技能名以兼容已有调用方式。

## 先确定交付范围

- 只说“改这份 PPT”：交付改版演示稿；不自动扩展为教案与任务单。
- 教师研修、报告、诗词赏析：按材料组织内容，不套四任务、四钥匙或固定 30 页。
- 明确要教学三件套：读取 [teaching-kit.md](references/teaching-kit.md)，用同一内容源锁定三份材料。
- 用户指定的页数、风格、教材、用途优先。材料文件名与内容不符时先指出，确认后继续；其他能推断的设计选择自主完成。

## 默认流程

按 [workflow.md](references/workflow.md) 完成：读全材料 → 锁定内容与设计 → 制作内部初稿 → 逐页自审 → 修订 → 重渲染复查 → 首次交付。制作布局前读 [visual-design.md](references/visual-design.md)，交付前读 [quality-checklist.md](references/quality-checklist.md)。工具与旧脚本边界见 [toolchain-pitfalls.md](references/toolchain-pitfalls.md)。

## 关键要求

1. **自主完成视觉判断**。根据主题、受众和用途选风格；不默认要求用户提供模板或当设计总监。水墨、童话绘本都是案例，不是通用主题。
2. **正文页同样是设计重点**。封面漂亮、几页有图，不能说明整套完成。逐页判断主要内容是否形成完整构图，重点是否足够大，空白是否有作用。
3. **空不等于高级，满不等于充实**。信息少时优先放大重点、展开对照或关系、加入有用的例子和贴题视觉；不靠重复文字、无关插画、卡片堆砌填空。
4. **图文融合并保留编辑性**。背景、插画可图片化；题干、原文、答案、主要文字、表格、图表和需要修改的关系图保持原生可编辑。学生原作、照片可保留证据图片，不冒充原生文本。
5. **先在内部完成返工**。初稿不是默认交付稿。实际渲染所有页，发现问题后修改、重渲染并复查受影响页；不能只检查封面、靠缩略图判断或只运行程序校验。
6. **内容与技术均真实**。不为了美观删掉必要材料，不把缺失视频说成已恢复，不把生成成功或结构 PASS 说成审美达标、已在 PowerPoint 实测。

## 参考与旧资源

- [正文页改版案例](references/approved-content-pages.md)：这次用户认可的改法、适用边界、样张索引。需要校准正文构图时读取，并实际看图。
- `assets/reference_pages/reading-inquiry-v2/`：用户认可的正文页样张，只供比较构图与可读性，不把截图整页塞进新课件。
- `scripts/build_kit.py`、`run_all.py`、示例 JSON 和旧插画保留为固定结构教学三件套工具。它们不是默认设计引擎，也不替代本流程的逐页目检。
- `assets/visual_tokens.json`、旧 `.slide` 与旧六页参考的固定参数，只适用于对应示例或明确要求复用的项目。

## 交付

交付完成自审的实际文件和适量正文预览。说明影响使用的限制；不自评“高级”、不承诺每次一稿通过。不把发现和修正明显空页的责任交给用户。后续用户反馈到来时，检查同类页面并统一修订。
