# 安装与使用 V2.0

本包将原高审美工作流、教学材料一致性方法和正文页自审修订整合到同一技能。保留技能名 `ppt-to-teaching-kit`，现有脚本与示例仍在。

## 支持技能的客户端

将完整 `ppt-to-teaching-kit` 文件夹放入客户端的技能目录。Codex 默认是 `~/.codex/skills/`，或实际配置的 `$CODEX_HOME/skills/`。若目标已有自己修改的版本，先保留备份并比较差异。其他平台使用其实际技能路径，不假定工具链与 Codex 相同。

更新后新开会话，让客户端重新发现技能。可这样调用：

> 使用 ppt-to-teaching-kit 改造这份课件。按 V2.0 的正文构图与内部自审修订流程，交付可编辑 PPTX。

只做 PPT 不会默认附加教案与任务单。明确要求三件套时再使用相应模式。

## 不支持技能的 AI

上传整个包，或读取 `SKILL.md` 与其指向的 `references/` 文件。阅读样张用于理解构图，不能直接把整页样张当作可编辑成品。生成工具、渲染和文件输出按目标平台实际能力适配。

## 依赖

默认设计流程不绑定某一个 Python 生成器；按目标平台的演示文稿、文档与图像能力执行。

只有主动选择固定模板脚本时，才需要对应 Python 的 `python-pptx`、`python-docx` 等依赖。`render_preview.py` 使用的 Windows PowerPoint/pywin32 不是默认流程的唯一预览方式。

## 版本范围

V2.0 的默认入口是 `SKILL.md` 和新 `references/`。旧六页样张、`visual_tokens.json`、固定模板和 `.slide` 只在明确复用相应示例时适用。脚本结构检查通过不代表审美通过；所有交付仍经过逐页视觉审阅。
