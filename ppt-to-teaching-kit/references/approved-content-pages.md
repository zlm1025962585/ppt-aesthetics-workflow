# 用户认可的正文改版案例

案例：《梳理与探究读写进阶》。原上传文件名《第一场雪(1).pdf》，实际为 18 页教师研修材料，改版为 20 页。

## 反馈与改法

第一版：有山水封面、瀑布页和动物页，但多张正文是小标题加少量文字、大面积纸色空白。用户反馈：“除了有图的那几个，其他感觉整个有点空。”

修订版：重做 12 页正文，增加贴题场景、放大数字与问题、展开关系、加入写作示例，并调整插画与文字冲突。用户反馈：“这个可以。”

后续用户要求整合工作流，因为这次仍依赖反馈才达到可用程度。因此，V2.0 将正文构图检查与修订放到首次交付前；不把这次认可推断为任何主题都用水墨或每页都加图。

## 样张索引

目录：`assets/reference_pages/reading-inquiry-v2/`。

| 样张 | 用途与判断重点 |
|---|---|
| `03_poems.png` | 双诗对照与对应场景融合；较长原文仍可编辑 |
| `05_poetry-culture.png` | 抽象内容用关键词与书卷场景组织，引用清楚 |
| `06_numbers.png` | 放大数字并配竹林、鸟鸣场景；文字净区实际检查 |
| `08_exercise.png` | 无插画也可充实：大选项、大诗句、明确行距 |
| `13_idioms.png` | 文字材料靠密度、分组与层级组织，不硬加图 |
| `14_relations.png` | 原生关系图展开分支；连接线不绕框、不穿字 |
| `15_writing.png` | 大步骤编号、行动提示、示例与书卷场景融合 |
| `19_summary.png` | 学习路径展开，每一步对应具体行动 |

样张是比较依据，不是必须照抄的模板。审阅新稿时先看其内容与用途，再比较重点尺寸、图文关系、空白用途和整体完成度。不要用截图替代新稿的原生文字，也不要从照片或例子推测额外事实。
