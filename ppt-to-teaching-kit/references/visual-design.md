# 正文构图与图文融合

## 用内容决定充实方式

| 内容 | 优先设计方式 | 需要防止的问题 |
|---|---|---|
| 诗文与赏析 | 诗意场景融入背景，原文独立排版 | 图只出现在封面；山石枝叶压住诗句 |
| 数字、词语比较 | 放大关键词，用位置和字号明确对照 | 两段小字挤在左侧，右侧毫无作用 |
| 追问与讨论 | 让核心问题成为视觉重点，分清发言层次 | 平均字号、对话冗长、依赖空白充场面 |
| 练习题 | 大字号选项、清楚的行距与分隔、必要作答空间 | 为了有图挤压题干；答案提前泄露 |
| 方法与写作指导 | 大步骤编号、行动提示、一个有用的示例 | 重复口号、统一小卡片、缺少可操作内容 |
| 关系图 | 原生节点与连线，按实际关系布局 | 仅用长箭头串标签；自动连线绕框或穿字 |
| 学生原作与照片 | 放大证据，旁边点出观察依据 | 证据太小、切断文字行、用装饰图替代证据 |
| 总结 | 展开学习路径，方法与例子相互对应 | 只剩标题和一句泛泛口号 |

## 画面要完整

- 每页有明确的视觉重心，标题、主要信息与图像之间有关系。不要把“留白多”自动当作高级，也不要规定所有画面必须填满。
- 少量内容可放大；并列内容可比较；抽象内容可给真实示例；复杂内容可分层或拆页。以原内容与教学目的为依据，不增加无关模块。
- 同一套保持字体、色彩和插画语言一致，构图随内容变化。避免连续多页重复同一小标题、同样大小的文字和大片无用途的空白。
- 以 1280×720 画布为例，可从标题约 44–60px、主要正文约 30–40px 起步，再依据语言、行数和用途调节。它们是起点，不是通用阈值；不要把 px 与 pt 混用。

## 图片服务内容

- 先决定图像承担什么作用：表现诗意、解释内容、提供证据或组织视线。没有作用就不强行加图。
- 素材生成前写清文字净区、主体位置、纵横比、细节集中区域与无需文字的要求。插入后检查实际图像，不能假设提示词保证了净区。
- 用自然晕染、裁切和适量渐变衔接图文，避免硬边矩形拼贴。主题主体不变形，证据不裁掉关键部分。
- 文字与枝叶、山体、器物打架时，调整构图、文字位置、裁切或柔和蒙层；不要只一味缩字。遮罩不能把整页图片洗成无意义的浅色装饰。
- 可重复使用有明确系列作用的背景，不默认全套重复同一幅画。全页参考截图用于学习构图，不当作新稿的可编辑正文。

## A / B / C 页面策略

- A 视觉主导：封面、情境、章节、结束页可大量图片化；需后续编辑的标题仍尽量独立。
- B 图文融合：知识讲解、阅读分析、方法说明通常采用图像加原生文字。这是最容易出现“有封面、无正文设计”的部分，要逐页看。
- C 功能主导：练习、表格、数据图表、关系图优先原生编辑性；清楚完整的纯文字页也可通过验收。

不以图片数量、图像覆盖率、蒙层数量或固定版式作为整套审美的代替指标。旧模板的这类参数仅用于它自己的示例。
