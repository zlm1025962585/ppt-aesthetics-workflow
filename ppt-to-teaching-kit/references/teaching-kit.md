# 可选：课件、教案、任务单三件套

仅在用户要求配套材料或明确选择该模式时读取。普通课件改版和教师研修不套四任务、四钥匙、30 页与 20 分的示例框架。

## 内容锁定

同一份结构化内容源保存课文版本、题干、任务名、方法、口诀、答案、分值、评分要点与易错提醒。多个文件从同一来源取值。按需使用 `assets/content_lock_template.md` 和示例 JSON，不凭记忆反复复制。

关键引文保持原文。版本不明或需要补全材料时核实对应版本；不要混入其他教材改写句。答案、评分和题干可相互对应，分值相加准确。任务单保留支架与书写区，不印示例答案。

## 教学结构

根据实际课型安排呈现材料、提问、尝试、方法、讲解、修改等环节，不强迫每节课都有同一九环节。用户选择四任务闯关示例时，可复用四任务九环节与钥匙结构，并确认三份文件对齐。

## 保留的固定模板工具

`scripts/run_all.py` 调用 `build_kit.py` 生成固定结构三件套，并做相应内容一致性与视觉底线检查。它适合复用该示例；不是高审美工作流的通用版式引擎。

```bash
python scripts/run_all.py --demo --out-dir ./work/demo
python scripts/run_all.py --content content_lock.json --out-dir ./outputs --prefix "课文名"
python scripts/consistency_check.py --config check.json
```

先按环境说明检查实际解释器和依赖。Codex 当前演示文稿、文档技能对生成工具有要求时，遵守当前技能，旧脚本只作内容或版式参考，不以本技能覆盖宿主要求。

示例固定的页数、配色、图片数量和渐变阈值只说明这个模板是否按预期生成。全部 PASS 后仍需按 V2.0 主流程逐页审阅成品；不能仅抽检封面或用“至少三页有图”推断整套可用。

本文不改变现有脚本行为。自定义版式稿应采用与实际请求对应的检查，不通过降低旧检查阈值来隐藏真实问题，也不把不适用的模板阈值硬套到新稿。
