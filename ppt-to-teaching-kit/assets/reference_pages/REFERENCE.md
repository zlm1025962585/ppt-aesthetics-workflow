## 版面铁律（从这六页提炼）

1. **一页只有一张满版图**：封面。其余页面图片只做局部面板或横幅，不做背景铺底。
2. **图上压字必须有蒙层**：白色字压图时，蒙层底部不透明度 ≥ 60%；否则字会被吃掉。
3. **标题三层结构**：圆形编号 / 橙色小标 / 32pt 深绿标题 + 1px 主色贯通细线。不省略细线。
4. **卡片统一圆角**：视觉半径约 12px（`adjustments≈0.06–0.10`），描边用 `#C8E6C9`，强调卡用 `#FB8C00`。
5. **正文都在可编辑文本框里**，不把题干或答案做成图片。
6. **页脚固定**：左下"情境 · 角色"，右下"N / 总数"，14pt 灰字，距底 30px。

## 与本 skill 生成结果的三处有意差异

| 位置 | 参照页 | 本 skill | 原因 |
|---|---|---|---|
| 第 2 页 | 无插画，右侧绿色任务面板 | 右栏 520×720 寒冬插画 + 横向蒙层 | 直接对应"花园被冬天困住"，且保证全篇至少三页有插画 |
| 章节页右上 | 装饰性钥匙图标 | 四把钥匙进度条（已收集/进行中/待收集） | 装饰换成信息，学生一眼知道进度 |
| 页脚 | "情境 · 角色 · 挑战一" | "情境 · 角色" + 页码 | 减少每页重复文字 |

这三处是**功能增强**，不构成视觉退化；除此之外的版式、字号层级、配色、留白应与参照页一致。

## 禁止事项（会被 `visual_check.py` 或人工验收判失败）

- 只有纯色块和文本框、没有任何插画的课件（"能看但难看"的典型症状）。
- 同一张插画在每页反复铺底（"全套背景重复"）。
- 插画被拉伸变形（必须按 cover 规则裁切，见 `Deck.picture()`）。
- 白字直接压图、无蒙层；或蒙层过深把插画糊成一片色块。
- 装饰元素压住正文；一页出现超过 4 种文字样式。

## 自检顺序

```bash
python scripts/run_all.py --content content_lock.json --out-dir ./out   # 内容一致性 + 视觉底线
python scripts/render_preview.py ./out/<名称>_学生课件.pptx ./preview 1 2 6 7 10 30   # 仅 Windows+PowerPoint
```

`render_preview.py` 需要本机安装 PowerPoint（Windows）；没有就跳过，靠 `visual_check.py` 的确定性断言兜底。
